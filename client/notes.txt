JWT token verification:
previously we were just storing and deleting jwt not verifying it, now to make website secure jwt verification is important while fetcing user data to frontend like to check if token is valid or not its expired or not etc., 
In this code JWT verification is done while sending username and email to frontend. Its a part of below implementation. 
It will verify the identity of user without storing session info on server.
User login/register -> jwt token generation (signs token with secret key, hashing it) -> token verification (token is taken from client and server, server contains the secret key for verification and creates token from this secret key, now both client and server generated token is compared.)
JWT token is stateless, means to session is not created. So thers's two step verification 1st login 2nd token verification.
