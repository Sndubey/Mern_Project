frontend part (client):
1: npm create vite@latest in MERN PROJECT folder.
2: give project name (like client)
3: choose react as framework and javascript (typescript recommended) as variant.
4: now cd client, npm install, npm run dev (to run the react project).
5: here we have used vite instead of create-react-app for frontend, but development language is only pure react. (recommended to use typescript with react).

Creating navigation bar:
1: using react-router-dom so that going at any page of nav bar doesnt refresh the page.
2: npm i react-router-dom
3: import {BrowserRouter, Routes, Route} from "react-router-dom";
4: do the coding in App.jsx to set the routers.
5: now create the pages folder which contains the elements of navbar like About.jsx, Home.jsx etc.
6: to create the frontend of navbar create components folder in src folder, import navbar elements stored in pages folder into Navbar components to create navbar.
7: now import Navbar component in App.jsx and use the component btw <BrowserRouter> and <Routes> bcz we want to display navbar in every page.
8: now if we want that page doesnt refresh after routing from one page to another import {NavLink} from 'react-router-dom'; and do the frontend coding using Navlink tag instead of anchor tag ,(it stops the refershing by storing the visited page data into browser in stack).
9: add css in Navbar.css

sending data from frontend to db.
1: In the code, inside the function which is called after form submit write this type of code:  (for register) 
try {
    const response = await fetch(`http://localhost:5000/api/auth/register`, {
        method: 'POST',
        headers: {
            "Content-Type": "application/json"
        },
        body: JSON.stringify(user)
    });
    if (response.ok) {  // if data successfully sended to db then empty the input field.
        setuser({
            username: '', email: '', phone: '', password: ''
        })
        navigate('/login');  //if reg. successful then send user to login page.
    }
    console.log(response);
} catch (error) {
    console.log("register error", error);
}
